# مدار — Madar

واجهة سطح مكتب مخصّصة لأوبنتو، مبنية على **Hyprland** و **Quickshell**.
شريط جانبي عائم، وشاشة رئيسية بالكروت، ومركز تحكم، وإشعارات، وشاشة قفل، ووضع ليل ونهار تلقائي.

اتعملت واتجرّبت على **ThinkPad E16 Gen 2 (Intel)** بنظام **Ubuntu 26.04 LTS**.

---

## المميزات

| الجزء | فيه إيه |
|---|---|
| **الشريط الجانبي** | البرامج المثبّتة والمفتوحة، ولو البرنامج ليه كذا نافذة بيعرضهم بمعاينة، وأيقونات البرامج اللي في الخلفية، ولغة الكيبورد، والبطارية، والساعة. بيلزق في طرف الشاشة لما نافذة تتكبّر. |
| **الشاشة الرئيسية** | بتظهر لما المساحة فاضية: الساعة، والطقس، والتقويم، والموسيقى، وحالة الجهاز، وبرامجك، وأزرار الجلسة. |
| **البحث (Super + D)** | البرامج، والملفات، وحاسبة (`150*12`)، وبحث جوجل، و `>` لتشغيل أي أمر. |
| **مركز التحكم (Super + N)** | قائمة الواي فاي، وأجهزة البلوتوث، واختيار السماعة والمايك، والإضاءة، والصوت، وفلتر الضوء الأزرق، ووضع الطاقة، والليل والنهار، ولون الواجهة، والإشعارات. |
| **النوافذ** | كلها عائمة زي ويندوز، وبتفتح بحجم مناسب في النص. فيه تكبير، ونص الشاشة يمين وشمال، وتصغير للشريط، و Alt + Tab، وشاشة لكل النوافذ (Super). |
| **أدوات** | تصوير الشاشة، وسجل الحافظة (Super + V)، ومؤشر الصوت والإضاءة، وشاشة القفل. |
| **الأوفيس** | OnlyOffice لملفات Word وExcel، بخطوط متوافقة مع ويندوز والعربي. التفاصيل تحت. |
| **الشكل** | ليل ونهار تلقائي (من ٦ الصبح لـ ٦ المغرب)، و ٤ ألوان للواجهة، وأيقونات WhiteSur زرقاء. وكل اختياراتك بتتحفظ. |

## الأوفيس

السكربت بيسطّب **OnlyOffice** (Word وExcel وPowerPoint) من المستودع الرسمي، فبيتحدّث مع باقي النظام.

- **الخطوط:** خطوط مايكروسوفت المجانية (Arial وTimes New Roman وغيرهم)، وبدائل بنفس المقاسات لـ Calibri وCambria، وخطوط عربي (Amiri وNoto Naskh وScheherazade)، عشان الصفحات ماتتزحلقش.
- **دقة 100% مع ويندوز:** لو عندك ويندوز على نفس الجهاز أو فولدر الخطوط بتاعه على فلاشة، شغّل `madar-fonts`. بيلاقي ويندوز لوحده، أو اديله مكان الفولدر: `madar-fonts /path/to/Fonts`. و `madar-fonts --list` بيوريك الخطوط المهمة الموجودة والناقصة.
- **فتح الملفات:** ملفات docx وxlsx وpptx (والقديمة doc وxls) بتفتح في OnlyOffice على طول.
- **ملف جديد:** كليك يمين في الملفات ← New Document ← Word Document أو Excel Workbook (مقاس A4).
- **الشكل:** فاتح وغامق مع ليل ونهار مدار، والنافذة بتفتح كبيرة في النص زي باقي البرامج الكبيرة.

## التركيب

<div dir="ltr">

```bash
git clone https://github.com/msha112/madar.git
cd madar
./install.sh
```

</div>

السكربت بيعمل كل حاجة:
- بيسطّب البرامج المطلوبة، ومنها Quickshell من مستودع DankLinux.
- بيسطّب أيقونات WhiteSur.
- بيضيفك لمجموعة `video` عشان أزرار الإضاءة تشتغل.
- بيحط ملفات الإعدادات في مكانها، **وبياخد نسخة من القديمة الأول** في `~/.config/madar-backup/`.
- بيظبط البوابات عشان البرامج ماتتأخرش في الفتح.

وبعدها: **أعد تشغيل الجهاز**، وفي شاشة الدخول دوس على الترس واختار **Hyprland**.

واجهة أوبنتو العادية بتفضل موجودة، وتقدر ترجعلها في أي وقت من نفس الترس.

**للتحديث بعد كده:**

<div dir="ltr">

```bash
cd madar && git pull && ./install.sh --files
```

</div>

`--files` بينسخ الملفات بس، من غير ما يسطّب برامج أو يطلب باسورد.

## الاختصارات

| الاختصار | الوظيفة |
|---|---|
| **Super** (لوحده) أو **Super + Tab** | كل النوافذ المفتوحة |
| **Alt + Tab** | التنقل بين النوافذ |
| **Super + D** | البحث والبرامج |
| **Super + N** | مركز التحكم |
| **Super + V** | سجل الحافظة |
| **Super + L** | قفل الشاشة |
| **Super + ↑** | تكبير / رجوع |
| **Super + ← / →** | نص الشاشة شمال / يمين |
| **Super + ↓** | رجوع للحجم العادي |
| **Super + M** | تصغير للشريط |
| **Super + T** | تقسيم تلقائي للنافذة / رجوع |
| **Super + F** | ملء الشاشة |
| **Super + C** | قفل النافذة |
| **Super + E** | الملفات |
| **Super + Enter** | الطرفية |
| **Super + 1…5** أو ٣ صوابع | مساحات العمل |
| **Alt + Shift** أو **Super + Space** | عربي / إنجليزي |
| **Print** أو **Super + Shift + S** | تصوير جزء من الشاشة |
| **Ctrl + Print** / **Shift + Print** | تصوير النافذة / الشاشة كلها |
| **Super + Shift + M** | الخروج من Hyprland |

## الملفات

<div dir="ltr">

```
quickshell/            the shell → ~/.config/quickshell/
  shell.qml            entry point
  Theme.qml            colours, day/night, accent, saved settings
  Sidebar.qml          side rail
  Home.qml             home screen
  Launcher.qml         search / launcher
  ControlCenter.qml    control center
  Overview.qml         all windows (Super)
  Switcher.qml         Alt + Tab
  Clipboard.qml        clipboard history
  LockScreen.qml       lock screen
  Notifications.qml    notification server + popups
  WindowRules.qml      how new windows open
  scripts/             snap.sh · max.sh · screenshot.sh
hypr/hyprland.conf     → ~/.config/hypr/
config/                fonts + desktop portals
ISSUES.md              known problems and fixes
```

</div>

الاختيارات اللي بتعملها من الواجهة (اللون، والليل والنهار، ومدينة الطقس، والبرامج المثبّتة) بتتحفظ في `~/.local/state/madar.json`.
ولتثبيت مدينة الطقس، اكتب اسمها هناك: `"city": "Cairo"`.

## مشاكل معروفة

موجودة بالتفصيل في [ISSUES.md](ISSUES.md). أهمها:
- **زرار التصغير اللي جوه البرامج بيجمّدها**، لأن Hyprland مش بيدعم التصغير. صغّر من الشريط الجانبي أو بـ **Super + M**.
- **الضغط على إشعار صورة الشاشة مش بيفتحها.** الصورة بتتنسخ وبتتحفظ في `Pictures/Screenshots`.
